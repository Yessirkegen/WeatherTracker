# WeatherTracker

## Описание проекта

WeatherTracker — это погодное веб-приложение с функциями аутентификации, переключения темы (светлая/темная) и фильтрации данных о погоде.

## Основные функции

1. **Аутентификация**: Вход, выход и регистрация пользователей с сохранением сессии в Local Storage.
2. **Настройки пользователя**:
    - **Светлая/Тёмная тема**: Пользователь может выбирать между светлой и тёмной темой, и выбор сохраняется между сессиями.
    - **Фильтрация погоды**: Сохраняет настройки фильтров, включая диапазон температуры и погодные условия (солнечно, облачно, дождливо).
3. **Полированный дизайн**: Поддержка респонсивности и единый цветовой стиль для всех устройств.

## Дизайн и типографика

- Приложение поддерживает светлую и тёмную темы, с плавной анимацией переключения.
- Используется адаптивный дизайн для удобного просмотра на любом устройстве.
